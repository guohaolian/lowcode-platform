# LowCode Studio

一个基于 Vue3 Composition API 的低代码平台，包含四大模块：

## 功能模块

- **📋 表单设计器**：拖拽组件、属性配置、撤销/重做、预览、导出 JSON
- **🎨 页面搭建**：自由布局拖拽、调整大小、属性配置、双击编辑文字
- **🔀 流程编排**：节点连线、拖拽移动、贝塞尔曲线连线、属性配置
- **📊 报表设计**：ECharts 图表、KPI 卡片、数据表格、栅格布局

## 快速启动

```bash
npm install
npm run dev
```

打开浏览器访问 http://localhost:5173

## 技术栈

- Vue 3 + Composition API + `<script setup>`
- Vite
- ECharts 5
- 纯 JavaScript（无 TypeScript）
